## Telegram Bot for the Periodic Table API

A Telegram bot integrated with the [Periodic Table API](https://periodictableofelements.org/api/) to display and summarise key information about any of the known chemical elements.

Includes multi-user support through [Peewee ORM](http://docs.peewee-orm.com/en/latest/).

---

### Installation

The project is portable and can be set up by following the steps below:
1. Clone the repository
```sh
git clone https://gitlab.skillbox.ru/mariia_kovalchuk/python_basic_diploma.git
```
2. Get a Telegram bot token through [@BotFather](https://t.me/BotFather) and store it in a `.env` file as shown in `.env.template`
3. Install dependencies into a virtual environment by running
```sh
python -m venv venv/
source venv/bin/activate
pip install -r requirements.txt
```

The project can be launched inside the directory containing the project by running `python main.py`.
